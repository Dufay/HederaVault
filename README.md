HEDERAVAULT

HederaVault is an open-source self-custody wallet for the Hedera network, designed around security, transparency, and air-gapped signing.

The project begins as a desktop wallet and evolves toward a dedicated offline signing device built from affordable, readily available components that anyone can assemble and verify.

VISION

HederaVault aims to provide a secure and fully open ecosystem for managing Hedera accounts, assets, and transactions without relying on proprietary hardware or closed-source software.

The long-term goal is to create a purpose-built air-gapped signing platform for Hedera that gives users complete control over their private keys while remaining accessible, auditable, and easy to reproduce.

CORE PRINCIPLES

 - Open source software

 - Open hardware

 - Verifiable security

 - Self-custody by default

 - No vendor lock-in

 - Offline-first transaction signing

INSPIRATION

HederaVault is inspired by the ideas and philosophy behind SeedSigner, an open-source air-gapped Bitcoin signing device focused on transparent, verifiable self-custody. While HederaVault is designed specifically for the Hedera ecosystem, it shares many of the same guiding principles:

 - Air-gapped security

 - QR-based workflows

 - Commodity hardware

 - Open-source development

 - User sovereignty

SeedSigner demonstrated that secure signing devices can be built using affordable, readily available components rather than proprietary hardware. HederaVault seeks to apply similar ideas to the Hedera network.

PROJECT ROADMAP

 - Phase 1 – Desktop Wallet

 - Testnet support

 - Account creation

 - Secure key storage

 - HBAR transfers

 - Transaction history

 - Wallet backup and recovery


Phase 2 – Expanded Hedera Support

 - HTS token support

 - NFT support

 - Multi-account management

 - Smart contract interaction


Phase 3 – Offline Signing

 - Transaction freezing

 - Offline signing workflows

 - QR-based transaction transport

 - Import and export of signatures


Phase 4 – Dedicated Signer

 - Standalone signing application

 - Fully air-gapped operation

 - Hardware reference designs

 - DIY assembly documentation


Phase 5 – Open Hardware Device

 - Commodity components

 - Reproducible builds

 - Community-manufacturable hardware

 - Secure self-custody for the Hedera ecosystem


Planned technologies include:

 - Rust

 - Tauri

 - React

 - SQLite

 - Hedera SDKs

 - QR-based transaction transport

Current Status

 - Early development.

The initial focus is creating a robust desktop wallet on Hedera Testnet that supports key generation, secure storage, account management, transaction creation, and transaction signing.
